## Judge walkthrough

1. On Resolve, run **True Duplicate**. Inspect the input, reference, extracted attributes and proposed common material code.
2. Run **Dangerous Near-Match**. Inspect the grade conflict and separate code previews. Change the grade with the counterfactual and compare the same reference again.
3. Run **Ambiguous Material**. Show that missing information leads to review rather than an invented equivalence.
4. Send a case to Review Queue, record a reason, make the decision, reload and export its history.
5. Import the provided sample CSV or a small XLSX file in Bulk Migration. Resolve, review and roll back a batch action.
6. Use Identity Graph and Research to explain clustering, the historical submitted result, the current known-set comparison and their limits.

A UI improvement or a passing synthetic benchmark cannot establish a 97+ external jury rating or a winning probability. Independent engineering labels, unseen-source evaluation and a real operational pilot remain the evidence needed to substantiate broader claims.
